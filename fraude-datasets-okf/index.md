# Fraud Detection Dataset Knowledge Base

This knowledge bundle organizes datasets related to phishing, spam,
and scam detection using the Open Knowledge Format (OKF).

The bundle separates raw data from the metadata and documentation
used to describe each dataset.

## Datasets

See the [dataset collection](datasets/index.md).

## Structure

- `datasets/`: OKF documents describing each dataset
- `raw/`: original dataset files

## Available Datasets

- [Phishing Dataset](datasets/phishing-dataset.md)
- [SMS Spam Collection](datasets/sms-spam-collection.md)

## Notes

The SMS Spam Collection is available through both Kaggle and Unicamp.
These are distributions of the same underlying dataset and are therefore
represented as a single dataset in this knowledge bundle.
